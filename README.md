# Secure Digital Wallet Payment System

A Java-based desktop application developed using Object-Oriented Programming (OOP) principles to simulate a secure and efficient digital wallet platform. The application allows users to register, log in, manage wallet balances, transfer money, view transaction history, and earn cashback rewards through a modern Java Swing graphical interface.

This project demonstrates the practical implementation of core OOP concepts, software engineering principles, file handling, and GUI development in Java.

---

## Project Overview

The Secure Digital Wallet Payment System is designed to provide a simplified model of modern digital payment applications. The system enables users to securely manage funds, perform transactions, and maintain transaction records while ensuring a smooth and user-friendly experience.

The project was developed as part of a Java Object-Oriented Programming course to demonstrate real-world application development using OOP principles.

### Objectives

- Develop a secure digital wallet application using Java.
- Apply Object-Oriented Programming concepts effectively.
- Create an interactive desktop GUI using Java Swing.
- Implement persistent storage using file handling.
- Simulate real-world digital payment functionality.
